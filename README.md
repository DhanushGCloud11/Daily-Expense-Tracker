# Daily Expense Tracker

A simple and responsive Daily Expense Tracker built using HTML, CSS, and Vanilla JavaScript.

## Features

- Add income and expense transactions.
- Edit existing transactions.
- Delete transactions.
- View total balance.
- View total income.
- View total expenses.
- Search transactions.
- Filter transactions by category.
- Filter transactions by type.
- Store data using Browser Local Storage.
- Responsive user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

daily-expense-tracker/

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open index.html in your browser.
4. Start adding your income and expenses.

## Data Storage

The application uses browser Local Storage to save transactions.

Your data remains available in the same browser unless its site data is cleared.
